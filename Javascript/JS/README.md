JavaScript là gì?

JavaScript, thường được viết tắt là JS, là một ngôn ngữ lập trình là một trong những công nghệ cốt lõi của World Wide Web, cùng với HTML và CSS. Nó cho phép chúng ta thêm tính tương tác vào các trang, ví dụ bạn có thể đã thấy thanh trượt, cảnh báo, tương tác nhấp, cửa sổ bật lên, v.v. trên các trang web khác nhau -- tất cả đều được xây dựng bằng JavaScript. Ngoài việc được sử dụng trong trình duyệt, nó cũng được sử dụng trong các môi trường không phải trình duyệt khác như Node.js để viết mã phía máy chủ bằng JavaScript, Electron để viết ứng dụng máy tính để bàn, React Native cho ứng dụng di động, v.v.
