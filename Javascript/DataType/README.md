# Lý thuyết về kiểu dữ liệu

Có 7 kiểu dữ liệu cơ bản

Number : số
String : chuỗi
Boolean : đúng sai
null : giá trị rỗng
undefined : chưa được gán giá trị
BigInt : số nguyên lớn
symbol : biểu tượng duy nhất

Kiểu dữ liệu tham chiếu

Object : đối tượng
Array : mảng
Function : hàm
