# Node.js

Node.js là một môi trường chạy JavaScript phía server, được xây dựng trên công cụ V8 JavaScript Engine của Google. Nó cho phép các nhà phát triển xây dựng các ứng dụng mạng hiệu năng cao, không đồng bộ và có khả năng mở rộng.

## Đặc điểm chính:
- **Không đồng bộ và hướng sự kiện**: Node.js sử dụng mô hình I/O không đồng bộ, giúp xử lý nhiều yêu cầu đồng thời mà không bị chặn.
- **Hiệu năng cao**: Nhờ vào V8 Engine, Node.js có tốc độ xử lý nhanh và hiệu quả.
- **Single-threaded**: Node.js sử dụng một luồng đơn (single-threaded) kết hợp với mô hình vòng lặp sự kiện (event loop).
- **Hệ sinh thái phong phú**: Node.js có một kho thư viện phong phú thông qua npm (Node Package Manager).

## Ứng dụng:
- Xây dựng API RESTful.
- Ứng dụng thời gian thực (Real-time applications) như chat, game.
- Xử lý file, streaming dữ liệu.
- Proxy server.
