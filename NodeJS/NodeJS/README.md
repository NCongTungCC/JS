# Khái Niệm

**Node.js** là một môi trường chạy JavaScript phía server, được xây dựng trên công cụ JavaScript V8 của Google Chrome. Node.js cho phép phát triển các ứng dụng mạng hiệu năng cao, không đồng bộ và dựa trên sự kiện.

## Đặc Điểm Chính
- **Không đồng bộ và hướng sự kiện**: Node.js sử dụng mô hình I/O không đồng bộ, giúp xử lý nhiều yêu cầu cùng lúc mà không bị chặn.
- **Hiệu năng cao**: Nhờ vào công cụ V8, Node.js có tốc độ xử lý nhanh.
- **Hệ sinh thái phong phú**: NPM (Node Package Manager) cung cấp hàng ngàn thư viện hỗ trợ.

## Ứng Dụng
- Xây dựng API RESTful.
- Ứng dụng thời gian thực (chat, game).
- Xử lý file và dữ liệu lớn.
